# Healthcare Operations & Patient Analytics Dashboard

## Project Overview
This project presents an interactive Healthcare Operations & Patient Analytics Dashboard developed using Microsoft Power BI.

The dashboard provides an overview of hospital admission records, patient demographics, medical conditions, insurance providers, billing revenue, and average length of stay.

The objective is to transform healthcare data into meaningful insights that can support hospital performance monitoring and data-driven decision-making.

## Dataset
- **Dataset:** Healthcare Dataset
- **Source:** Kaggle
- **Format:** CSV

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
- Data Cleaning and Transformation

## Key Performance Indicators (KPIs)
1. Total Admissions
2. Total Hospitals
3. Total Revenue
4. Average Billing Amount
5. Average Length of Stay
6. Average Patient Age

## Dashboard Visualizations
1. Admissions by Medical Condition – Treemap
2. Monthly Admission Trends – Line Chart
3. Admissions by Admission Type – Donut Chart
4. Revenue by Insurance Provider – Clustered Bar Chart
5. Admissions by Gender – Pie Chart
6. Average Length of Stay by Medical Condition – Clustered Column Chart

## Interactive Filters
- Gender
- Medical Condition
- Admission Type
- Insurance Provider
- Hospital

## Skills Demonstrated
- Data importing and transformation using Power Query
- Data analysis using DAX measures

- Interactive dashboard design

## Project Outcome
Developed an interactive dashboard to explore healthcare admission patterns, patient demographics, hospital distribution, billing performance, and length-of-stay metrics.

This project demonstrates practical Power BI skills and the ability to convert structured healthcare data into an interactive analytical report.
